## 简介

OmniStats 常驻菜单栏,一眼看到 SoC / SSD / 电池温度、功耗与风扇转速。和多数监控工具不同,它能在 Apple Silicon 上**真正调节风扇**——通过温度→转速曲线,并采用硬件友好的渐进调速。

面板还提供网速和 CPU 进程排行，资源卡片依次显示 CPU 使用率、内存、GPU 使用率（取决于驱动支持）、启动盘容量。资源读数不需要管理员权限，关闭面板即停止采集。

点击网络行，可在紧邻主面板的小窗中查看历史和应用网速；展开、收起均不改变主面板的大小和位置。

已在 **M5 Pro (Mac17,8)** 上完整验证。风扇控制适用于固件暴露可写风扇 key 的 Apple Silicon 机型(见[风扇控制原理](#风扇控制原理))。

## 功能

- 💻 整机 CPU 使用率、内存、GPU 使用率、启动盘已用 / 总容量
- 📉 平滑历史折线，保留原始采样值与真实数据断点
- 🔋 温度 / 网络 / 进程默认 10 / 3 / 10 秒，省电 30 / 10 / 30 秒；打开面板使用默认频率
- 🌡 菜单栏显示最高 SoC 温度 + 圆环仪表
- 📈 交互式**温度→转速曲线**,带实时工作点光标
- 🌀 **自动 / 手动 / 曲线** 三种模式;自动适配各机型不同风扇上限
- 🧊 **硬件友好调速**:温度 EMA 平滑 + 死区滞回 + 限斜率渐进——不会因 1° 抖动来回窜
- 🎛 一键曲线预设(静音 / 均衡 / 高性能)
- 🎨 深色 / 浅色"热学仪表"双主题，也可跟随系统
- 🔒 应用内一键安装 root 助手(系统原生授权一次,无需终端)
- 🚀 可选登录时启动(通用 → 启动)
- 🗑 卸载应用时连同设置、缓存、后台项、系统服务和特权助手一起移除(全部移到废纸篓)
- 🫥 把不常用的菜单栏图标收进「‹」,类似 Bartender,无需任何权限(macOS 13–26)
- 🔋 电池:电量、硬件电量、健康度(最大容量、循环次数)与实时功率流向,无需管理员权限;另可通过助手开启带航行模式的充电上限
- ⬆️ 内置更新检查,可一键自更新
- 🪶 原生 SwiftUI,极轻,无 Electron、无后台臃肿

## 安装

### 下载安装(推荐)

从 [Releases 页面](https://github.com/SuooL/OmniStats/releases/latest) 下载最新
**`OmniStats.dmg`**,打开后把 **OmniStats** 拖进 Applications。应用未经公证,首次打开会被拦截:
macOS 15 及以上请在**系统设置 → 隐私与安全性 → 仍要打开**;macOS 13–14 右键应用 → **打开**。
也可以运行 `xattr -dr com.apple.quarantine /Applications/OmniStats.app`。

发布版未经公证。从 1.6.0 起,发布版用一张固定的自签证书签名;macOS 会把你授予的隐私权限(如完全磁盘访问)绑定到这个签名,因此之后的更新应当不再需要重新授权。更早的版本为 ad-hoc 签名,所以升级到 1.6.0 时还需要再授权一次。

### 从源码构建

需要 Command Line Tools(`xcode-select --install`),无需完整 Xcode。

```bash
git clone https://github.com/SuooL/OmniStats.git
cd OmniStats
make
open dist/OmniStats.app
```

源码构建默认 ad-hoc 签名(传入 `SIGN_ID="<证书名>"` 可改用你自己的证书)。若首次打开被 Gatekeeper 拦截,按上文选择**仍要打开**,或:

```bash
xattr -dr com.apple.quarantine dist/OmniStats.app
```

### 启用风扇控制

在应用里点**启用风扇控制**,授权一次即可——OmniStats 会替你安装一个 root 助手(LaunchDaemon),无需终端。随时可在**关于 → 移除助手**卸载。

## 风扇控制原理

Apple Silicon 风扇由 SMC 管理。OmniStats 以 root 写两个 SMC key 来控制:

| Key       | 含义                                    |
|-----------|-----------------------------------------|
| `F<n>md`  | 模式 —— `0` 固件自动,`1` 手动           |
| `F<n>Tg`  | 目标转速(钳制到 `F<n>Mn`…`F<n>Mx`)     |

顺序:先 `F<n>md = 1`,再写 `F<n>Tg`。注意 M 系列是**小写** `md`(旧机型/Intel 是 `F0Md`);OmniStats 两者都探测。无风扇机型(如 MacBook Air)自动降级为纯监控。

温度取自私有 `IOHIDEventSystemClient` 传感器;风扇转速与功耗来自 SMC。

## 电池充电控制原理

充电上限由 root 助手自己执行,App 关闭后依然有效。

- 每 10 秒以及唤醒时,助手从 `AppleSmartBattery` 读取电量,达到上限时写入 SMC 键 `CHTE`(旧固件为 `CH0B`/`CH0C`)暂停充电。电量降到「恢复」值以下才重新充电(航行模式),电池不会在上限附近反复充放。
- **macOS 自身的充电上限**(系统设置 › 电池,macOS 26.4+)保留为安全兜底。只有系统设置能修改它;如果你的上限高于它,电池页会提示你去调高。
- 据报告,较新的固件更新(macOS 15.8 / 26.7 / 27)会拒绝这类写入。遇到这种 Mac,电池页会说明情况并引导你使用 macOS 自带的上限。
- 可选项:睡眠前暂停充电;充到上限前不进入闲置睡眠。**立即充满**会暂时解除上限,拔掉电源后恢复。
- **高温保护**:电池温度高于你设定的值(30–50 °C)时暂停充电,降温 3 °C 后恢复;「立即充满」时同样生效。
- **MagSafe 指示灯**:交给 macOS、显示充电状态(充电时橙色,其余绿色)或关闭。重新选择「系统」即交还给 macOS。
- **定时计划**(电池页):在指定的星期和时间重复执行设置上限、立即充满、开启或关闭限制。OmniStats 运行时生效;睡眠期间错过的计划会在唤醒后补做(12 小时内)。
- **自动化**:快捷指令的「打开 URL」(或终端里的 `open`)可以控制充电上限,只开放与上限相关的操作:

  | 链接 | 作用 |
  |---|---|
  | `omnistats://battery/limit?value=80` | 开启上限并设为 80%(20–100) |
  | `omnistats://battery/enable`、`…/disable` | 开启或关闭上限 |
  | `omnistats://battery/topup`(加 `?enabled=0` 取消) | 立即充满,拔掉电源后恢复 |
  | `omnistats://battery/led?mode=status`(`system`、`off`) | MagSafe 指示灯模式 |
  | `omnistats://settings/battery` | 打开电池设置页 |

- **放电与校准**会暂停电源适配器(SMC `CHIE`),让接着电源的 Mac 由电池供电:放电到指定电量、高于上限时自动放电回上限,或校准(充满 → 保持 1 小时 → 15% → 充满 → 保持 1 小时 → 回到上限,每一步自动进行;以 macOS 报告充电完成为准,屏幕显示 100% 后可能还要再充一阵)。放电快慢取决于用电量,轻度使用时全程接近一天,因此放电到 15% 这一步最长等 24 小时,期间低电量模式会暂时换成「自动」,结束后恢复。这两项刻意不通过链接或定时计划开放。

## 卸载应用

**设置 → 应用卸载** 会列出 /Applications 和 ~/Applications 中的应用(不含 Apple 自带应用),并找出每个应用留下的文件:应用数据、缓存、偏好设置、容器、窗口状态、网页数据、后台项与系统服务、特权助手和安装记录。保持勾选的项目都会移到废纸篓,可以恢复。

- 优先按应用标识符匹配;只因与应用同名而找到的文件夹会标注「按名称」,通用或厂商共用的文件夹(Google、Microsoft、"Uninstaller" 等)不会按名称匹配。系统服务还会按它指向的应用来识别。
- 先移除应用本身;如果 macOS 拒绝(App 管理),其他文件都不会动,并在界面上说明怎么处理。
- 系统文件夹中的项目由 `omnistats-cleaner` 移动:它只在管理员授权后运行一次,只接受固定几个文件夹的直接子项,拒绝符号链接和 `..`,不调用 shell,而且只移动、不删除。
- 其他应用的容器需要完全磁盘访问权限,没有权限时默认不勾选。ad-hoc 签名的构建(源码构建、1.6.0 之前的发布版)每次更新后都会失去这项授权。
- 每次卸载都会在 `~/Library/Logs/OmniStats` 中写一份日志。
- **重置…** 保留应用,只把所选的数据、缓存和设置移到废纸篓;应用本身、后台项、系统服务、特权助手和安装记录都会保留,下次打开就像刚安装一样。
- 由 Homebrew 安装的应用会标注出来,它的 cask 自带的清理清单(`zap`)也会加入列表(标为「Homebrew」),但只收卸载器本来就会接受的路径:绝不包括主目录或 Library 的根,主目录之外只收 `omnistats-cleaner` 允许移动的项目。在这里移除 cask 应用后,Homebrew 仍保留它的记录,所以界面上提供 `brew uninstall --zap --cask <token>` 供复制使用。
- **已删除应用的残留** 会扫描以已不在 Mac 上(Launch Services 也找不到)的应用命名的文件。只认反向域名形式的名称;属于已安装应用或同一厂商其他应用的文件、SDK 和系统数据(Amplitude、Crashlytics、CUPS、Swift PM 等)以及命令行工具的设置都会排除,后台项只有在它指向的程序已不存在时才算。所有项目默认不勾选,请逐项确认。

## 菜单栏图标

**设置 → 菜单栏图标**(默认关闭)会在 OmniStats 图标旁加上「‹」和分隔线「|」。按住 ⌘ 把不常用的图标拖到分隔线左侧,点击「‹」(或按快捷键)即可显示,到了设定的时间会自动收起。还可以开启虚线分隔的「始终隐藏区」,按住 ⌥ 点击或右键点击「‹」时才显示。

- 原理与 Hidden Bar 相同:收起时分隔线变得很宽,把它左侧的图标挤出屏幕。不需要辅助功能或屏幕录制权限,因此不受更新影响。
- 如果分隔线跑到了「‹」右侧,OmniStats 会拒绝收起(避免「‹」自己消失),并在设置页提示你拖回去。
- macOS 27 重做了菜单栏,会丢弃过宽的图标,因此暂不支持。

## 硬件友好调速

转速绝不被生拉硬拽,三层保证平滑:

1. **温度平滑** —— 驱动温度是指数滑动平均(~6 秒),瞬时尖峰不会引起风扇窜动。
2. **死区滞回** —— 新目标与当前指令差异在小范围内则不动,避免持续微调。
3. **限斜率** —— 真要调整时,指令按每秒最大步进渐进逼近。

三者均可在**风扇 → 高级配置**调节,并支持一键还原。

## 安全性

- 目标转速钳制在各风扇自身 `Mn`…`Mx` 区间。
- **看门狗**:应用断连或卡死时,所有风扇自动回落固件自动;退出应用也会还原。
- 仅极小的 `omnistats-smcd` 助手以 root 运行,并校验对端 uid,防止其他本地账户劫持风扇。如果助手使用证书签名,还会校验连接方的代码签名,只有同一证书签名的 OmniStats 才能向它发送指令;发布版从 1.6.0 起使用证书签名;ad-hoc 构建(源码构建、旧发布版)只依靠控制台用户校验。
- 充电控制出问题时一律放行充电:助手退出(卸载、关机)、读不到电池、关闭上限时都会恢复充电;检测到其他充电管理工具(AlDente、batt、Battery Toolkit)运行时不做任何写入;你没开启上限时,也不会碰充电相关的键。
- 暂停适配器是唯一可能让接着电源的 Mac 耗电的操作,因此以下情况会立即恢复供电:你拔掉电源(SMC `AC-W` 能区分真的拔线和我们的暂停)、Mac 即将睡眠、达到目标电量、10% 下限或 8 小时上限(校准放电到 15% 为 24 小时)、读不到电池、出现其他充电管理工具,以及助手启动或退出时。
